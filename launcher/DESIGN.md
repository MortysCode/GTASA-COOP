# Launcher design assets

The executable contains `CoopLauncher/Assets/hero.png` as a WPF resource.
The image was created using the built-in imagegen tool, without an API key or CLI fallback.
The rest of the interface is native WPF/XAML, not a screenshot placed over buttons.

Final generation prompt:

> Use case: illustration-story. Asset type: clean hero background artwork for the actual SA:COOP Windows launcher, not a UI mockup. Create a wide panoramic landscape image 16:7 composition. Los Santos / Grove Street neighborhood at golden orange sunset: modest California houses, palms, power lines, distant city towers; two adult male friends wearing green streetwear stand at the right beside a dark green lowrider, one standing facing down the street, another resting against car. Warm nostalgic early 2000s GTA San Andreas loading-screen illustration feeling: bold clean outlines, detailed painterly shading, orange sky, green and charcoal clothing, sophisticated game key art. Characters occupy right half; left half has a quiet darker foreground street/house area with generous readable negative space where the launcher will overlay its own heading. Skyline and palms remain visible across top. Straight horizontal composition, no dramatic fisheye. Absolutely no text, no logos, no interface, no buttons, no sidebar, no frame, no watermarks. Complete original artwork fills the image. High quality crisp illustration, not a photograph. This is an atmospheric cooperative-game launcher banner.
