SA:COOP 0.3.1.10 с Windows-лаунчером 1.1.1. Все прежние игровые функции сохранены; сетевой протокол по-прежнему 25.

При новой установке сборки 4GB-патч (LAA) автоматически включается в скопированном `gta_sa.exe`.
Исходный EXE сохраняется, уже включённый патч повторно не применяется. PE-контрольная сумма пересчитывается.
Файл GTA не скачивается: используется собственная совместимая GTA SA 1.0 US игрока.
Патч не превращает другую версию игры в 1.0 US. Обычные обновления SA:COOP существующий EXE не заменяют.

Новая кнопка **«Установить игру»** создаёт отдельную сборку из собственной GTA San Andreas 1.0 US игрока:

1. Выберите свою установленную GTA и новую папку назначения.
2. Лаунчер скопирует базовую игру, скачает пакет текущих модов и последнюю стабильную SA:COOP.
3. После установки нажмите «Играть». Ник и подключение настраиваются через F9 в игре.

Базовая GTA на GitHub не распространяется. Нужна собственная совместимая копия.
Пакет модов — около 952 МБ для скачивания, 2 ГБ после распаковки; временные файлы требуют дополнительного места.
Исходная GTA, её сохранения и настройки подключения не переносятся и не изменяются.
Новая установка требует пустой папки, проверяет контрольные суммы и поддерживает отмену.

Источник лаунчера закреплён: `MortysCode/GTASA-COOP`. Его нельзя изменить в настройках.

- Догонялки: 35 секунд на прятки, 10 минут погони, автоматическая смена ролей, `/endgames` возвращает игроков назад.
- Временная максимальная выносливость в миниигре с восстановлением прежнего уровня.
- `/pay`, `/afk`, `/givegun`, `/giveammo`, ранения, поднятие кнопкой E, `/revive`, `/giveup`.
- Лаунчер проверяет контрольные суммы, сохраняет резервные копии и восстанавливает файлы при сбое.

Игрокам: скачайте **SA-COOP-Launcher-win-x64.zip**, распакуйте и запустите EXE.
Для новой сборки используйте «Установить игру». Для обновления уже готовой игры выберите её папку в настройках.
Для ручного обновления доступен архив **SA-COOP-ВЕРСИЯ-update.zip** текущего релиза.
Файл **sa-coop-update.json** нужен лаунчеру; вручную открывать его не требуется.

Перед обновлением закройте GTA и сервер. Оба игрока должны использовать совместимые версии.
