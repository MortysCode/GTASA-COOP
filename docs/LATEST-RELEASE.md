SA:COOP с Windows-лаунчером 1.0.1 и обновлениями через GitHub Releases.

Источник лаунчера закреплён: `MortysCode/GTASA-COOP`. Его нельзя изменить в настройках.

- Догонялки: 35 секунд на прятки, 10 минут погони, автоматическая смена ролей, `/endgames` возвращает игроков назад.
- Временная максимальная выносливость в миниигре с восстановлением прежнего уровня.
- `/pay`, `/afk`, `/givegun`, `/giveammo`, ранения, поднятие кнопкой E, `/revive`, `/giveup`.
- Лаунчер проверяет контрольные суммы, сохраняет резервные копии и восстанавливает файлы при сбое.

Игрокам: скачайте **SA-COOP-Launcher-win-x64.zip**, распакуйте и запустите EXE.
Требуется установленная GTA San Andreas с ASI-загрузчиком и базовой сборкой SA:COOP.
Для ручного обновления доступен архив **SA-COOP-ВЕРСИЯ-update.zip** текущего релиза.
Файл **sa-coop-update.json** нужен лаунчеру; вручную открывать его не требуется.

Перед обновлением закройте GTA и сервер. Оба игрока должны использовать совместимые версии.
