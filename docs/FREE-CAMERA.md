# Обзор камерой в AFK и при ранении

Сборка **0.3.1.5**, протокол **23**. Включает прежние передачи оружия/патронов,
деньги, AFK и кнопку E для помощи раненому.

В обычном игровом обзоре можно вращать камеру мышью:

- в `/afk`, пока персонаж курит;
- при тяжёлом ранении, пока персонаж лежит и ждёт помощь;
- во время трёхсекундной помощи напарнику.

Отключение режима или поднятие персонажа для обзора не требуется. Действия персонажа
по-прежнему заблокированы: нельзя ходить, стрелять, прыгать или менять его занятие.
Анимации, подписи, защита от урона, таймер ранения и правила прерывания помощи сохранены.
Чат, меню, окно F9 и катсцены используют прежние ограничения камеры/интерфейса.

## Почему раньше камера замирала

GTA использует общий `CPad::DisablePlayerControls`: проверки обзорных направлений
тоже возвращают ноль при установленном флаге. AFK и ранение раньше выставляли
собственные биты в этом поле без разделения камеры и действий.

Теперь собственные блокировки учитываются через `entities/player/ControlLocks`.
Обработчик `CCamera::Process` временно снимает только принадлежащие моду биты на время
расчёта камеры. Сразу после возвращения из функции они восстанавливаются для обычной
симуляции персонажа. Блокировки миссий, телефона, катсцен и не принадлежащие моду биты
не сбрасываются. При открытом интерфейсе или катсцене исключение для камеры не применяется.

Завершение AFK/ранения внутри временной области не возвращает уже снятую блокировку.
Выход из сессии и загрузка мира очищают только собственные блокировки. Изменения
не записываются в сохранения или профиль и не требуют редактирования coop.ini.

## Установка

При закрытых GTA и сервере сохраните копии `coop.asi`, `coop/coop-server.exe` и
`coop/coop.pdb`, затем распакуйте `SA-COOP-FreeCamera-update.zip` в папку с `gta_sa.exe`
с заменой этих файлов. Установите обновление обоим игрокам для одинакового поведения.
Настройки подключения, сохранения, SilentPatch и Framerate Vigilante архив не заменяет.
Протокол 23 остаётся совместимым со сборками 0.3.1.3 и 0.3.1.4.

## Проверки

```
python tools/build.py dist
python tools/fsd_check.py
python tools/i18n_check.py
python tools/test_control_locks.py
python tools/test_afk.py
python tools/test_gear_rescue.py
```

Проверяются принадлежность блокировок, временное снятие только собственных битов,
возврат после расчёта камеры, сохранение новых ограничений игры, вложенные вызовы,
завершение режима внутри области камеры и очистка при отключении/загрузке мира.
Повторно выполняются проверки AFK и модели ранения/спасения.

Обзор мышью в двух игровых клиентах ещё не проверен. После установки проверьте поворот
влево/вправо и вверх/вниз в AFK и ранении, отсутствие движения/стрельбы, окончание режима,
открытие чата/F9 и начало катсцены. Для полноценной проверки ранения используйте отдельное
сохранение по инструкции COOP-TOOLS.md.

Адрес и поведение сверены с первичными источниками:
[CCamera::Process](https://github.com/gta-reversed/gta-reversed/blob/master/source/game_sa/Camera.cpp),
[CPad::LookAroundLeftRight / LookAroundUpDown / UpdateMouse](https://github.com/gta-reversed/gta-reversed/blob/master/source/game_sa/Pad.cpp).
